# Branch Sales Demand Forecasting

## Task
1. Train all regressor models covered in scikit-learn
2. Calculate RMSE, MSE, MAE
3. Check multicollinearity between features; remove/transform features with correlation > 0.95
4. Check skewness and kurtosis; apply log/standard/robust scaling as needed
5. Plot density graphs for distribution of every feature
6. Train regressors with baseline parameters first
7. Use Optuna for hyperparameter optimization; retrain and compare results
8. Perform XAI analysis using SHAP and LIME
9. Generate feature importance diagrams for all models

`forecasting-dataset.csv`
